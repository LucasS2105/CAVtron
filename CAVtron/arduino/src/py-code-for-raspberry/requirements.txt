# =============================================================
#  requirements.txt — Raspberry Pi Zero 2 W
#  Conversão do firmware Arduino para Python nativo no RPi
# =============================================================
#
#  Instalação:
#      pip install -r requirements.txt
#
#  Pré-requisitos via apt (instalar antes do pip):
#      sudo apt update
#      sudo apt install -y python3-pip python3-dev
#      sudo apt install -y python3-rpi.gpio     # GPIO
#      sudo apt install -y python3-spidev       # SPI (MCP3008)
#      sudo apt install -y python3-smbus2       # I2C (HuskyLens)
#
#  Habilitar interfaces no raspi-config:
#      sudo raspi-config → Interface Options:
#        ├── SPI    → Enable   (sensores de linha via MCP3008)
#        ├── I2C    → Enable   (HuskyLens)
#        └── Serial → Enable port, Disable console (se usar UART)
# =============================================================
